Cette adresse ne mène nulle part.

Le site DropForge est entièrement statique : il n'existe que les fichiers publiés. L'adresse demandée n'en fait pas partie — un lien tronqué, une page d'une ancienne version, ou une faute de frappe.

L'application est juste à côté

Elle n'utilise aucune adresse de page : ses écrans vivent après le # (par exemple {{BASE_URL}}app/#route=transfer). Rien de ce que vous faisiez n'est perdu pour autant : DropForge ne stocke rien sur ce site.

Ouvrir l'application Page d'accueil

Si vous suiviez un lien d'appairage ou de partage, il est peut-être incomplet : demandez-le à nouveau. Un code d'appairage voyage uniquement après le #, donc il n'apparaît dans aucun journal de serveur.
